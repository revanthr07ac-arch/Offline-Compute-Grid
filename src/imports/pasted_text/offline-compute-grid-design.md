Design a premium, modern, futuristic SaaS dashboard for a desktop and mobile application called "Offline Compute Grid".

The application is a decentralized offline distributed computing platform where multiple laptops, PCs, Raspberry Pis, and Android devices collaborate over a Local Area Network (LAN) to process computational tasks without requiring internet connectivity.

The UI should look like a combination of:

• Notion AI
• Vercel Dashboard
• Grafana
• GitHub Dark Theme
• Warp Terminal
• Tailscale Dashboard
